External Library / Development Log
====================================

[2026-09-02]

Game specification notes:
- Keyboard movement uses WASD or the Arrow Keys.
- The Arrow Keys may be assigned to camera-direction controls if that produces a better third-person control scheme.
- Stage environment: wilderness / wasteland.
- Third-person rear camera follows the player.
- Player uses a human-like body structure suitable for movement.
- The game is a GTA-style exploration / action / adventure game, using an original setting and assets.
- NPCs are action/behavior-only; no conversational NPC system is required.
- NPCs may be somewhat lighter than the player, but should not be arbitrarily simplified during development.
- Z + W means running. Input handling must support at least three simultaneous keys, including combinations such as Z + W + A/D.
- Visual/display information and internal/game/physics information must be handled separately and kept synchronized; physics/internal state is authoritative for physical placement.
- The sun's altitude, direction, illumination, shadows, and environmental lighting should be represented faithfully enough to feel natural rather than as an arbitrary fixed light.

External libraries:
- Rapier 3D: physics simulation and collision handling for the 3D game.
  Source: jsDelivr CDN, browser-compatible ESM build.
  Version: 0.19.0.
- Three.js: WebGL 3D rendering, scene management, camera, lighting, and model display.
  Source: jsDelivr CDN, browser-compatible ESM build.
  Version: r180 (0.180.0).

Implementation note:
- The initial implementation is designed for direct browser execution and static hosting such as GitHub Pages or Netlify.
- Physics state remains authoritative; Three.js objects mirror the resulting state for display.
- External library additions and removals must continue to be recorded here.
